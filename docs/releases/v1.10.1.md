# Sitting Duck v1.10.1

**Release date:** 2026-08-05

Windows glob path separators in tests.

On Windows, glob expansion yields native backslash separators, which failed
`duck_blocks.test`'s multi-file assertion against forward-slash literals
(community-extensions #2322, `windows_amd64`). The comparison now normalises
separators, matching upstream DuckDB test convention. (#98)
