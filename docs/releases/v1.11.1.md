# Sitting Duck v1.11.1

**Release date:** 2026-09-07

Bugfix checkpoint.

Not published to the community-extensions registry.

- Corrected the Universal Flags table to match the implementation: bit 0 is
  `IS_SYNTAX_ONLY` (`is_construct` is its inverse), with `NAME_ROLE` /
  `IS_SCOPE` / `IS_EXPORTED` documented and a stale "RESERVED 2-7" entry
  fixed. A reader deriving a filter from the old table got the inverse of
  what they intended. (#102)
