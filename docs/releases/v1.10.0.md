# Sitting Duck v1.10.0

**Release date:** 2026-07-24

Runtime-loadable tree-sitter grammars.

`register_language()` loads a tree-sitter grammar from a shared library at
runtime, with a JSON semantic config. (#80)

- JSON config maps node types to semantic types, refinement bits, name and
  native strategies; unknown keys and enum names error rather than being
  ignored.
- Gated behind external-access checks, with introspection and extension
  auto-detection.
- `ast_to_blocks` renders code structure as duck_blocks documents.
