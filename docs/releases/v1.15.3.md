# Sitting Duck v1.15.3

**Release date:** 2026-09-29

DuckDB v2.0 named parameters + Windows builds restored.

- DuckDB v2.0 removed `TableFunction::named_parameters`. Declarations now go
  through `GetSignature().WithTypedKwargs()` and lookups through an
  Identifier-keyed map; `named_parameter_compat.hpp` covers both lines from
  one source tree. (#183)
- Windows builds restored. The exclusion dated from the v1.5.4 era and had
  gone stale — the registry was already shipping `windows_amd64` and
  `windows_amd64_mingw`, so the repo could not see a Windows break until the
  registry did. (#182)
