# Sitting Duck v1.13.0

**Release date:** 2026-09-10

Name-binding sites resolve as definitions.

Name-binding sites were mis-flagged as references, so scope resolution,
`:definition` and `ast_find_references` under-counted. (#64)

- Function parameters across 14 languages, for-loop targets (python, rust,
  java), and exception-handler variables (js, ts, c#, ruby, java) now
  resolve as `NAME_DEFINITION`.
- Default values, iterables and use sites stay references — verified, no
  false definitions.
- Mechanism: per-adapter `IsBareNameDefinitionParent` /
  `IsBareNameDefinitionField` hooks consulted after the `.def` flags.
