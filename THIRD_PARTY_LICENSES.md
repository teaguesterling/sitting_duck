# Third-Party Licenses

sitting_duck bundles the [Tree-sitter](https://github.com/tree-sitter/tree-sitter)
runtime and language grammars as git submodules. Each retains its own `LICENSE`
file (under `third_party/tree-sitter/` and `grammars/<name>/`); this file
summarizes them. All are permissive (MIT or Apache-2.0), compatible with
sitting_duck's Apache-2.0 license.
