# Sitting Duck v1.11.0

**Release date:** 2026-09-06

DuckDB v2.0 compatibility, duck_blocks 6.5, grammar refresh.

- DuckDB v2.0 (cyanoptera) build and test compatibility — the extension is
  cross-version (v1.5.4 and v2.0), green on Linux and macOS. (#110, #113)
- duck_blocks: vocabulary and conformance synced to 6.5; `ast_to_blocks`
  emits `level >= 1` per the current spec. (#109, #111)
- 13 tree-sitter grammars bumped to latest tags and parsers regenerated;
  annotations contract A across extractors. (#107, #108)
- v2.0 architecture RFC. (#93)
