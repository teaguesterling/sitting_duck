# Sitting Duck v1.9.0

**Release date:** 2026-07-22

Compile-time language selection.

Each of the 27 built-in languages (vendored grammar + adapter + semantic
config) is now a build-time module.

- `-DSITTING_DUCK_LANGUAGES="python;cpp"` selects a subset (default: all),
  `-DSITTING_DUCK_EXCLUDE_LANGUAGES` subtracts. Unknown or empty selections
  fail configure with the valid list. (#92)
- Per-language wiring lives in one place, `cmake/BuiltinLanguages.cmake`;
  user-supplied lists are re-sorted into canonical registration order, so a
  subset still registers in a stable order.
