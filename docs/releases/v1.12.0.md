# Sitting Duck v1.12.0

**Release date:** 2026-09-08

Native `receiver` extraction.

Not published to the community-extensions registry.

- Native `receiver` field plus `[receiver=X]` selector, replacing a
  regex-over-peek approach with a structural, extraction-time value. (#86)
- One grammar-agnostic rule: member access `.` / `->` / `?.` yields the
  object's trailing simple name; scope `::` yields no receiver; bare,
  computed and chained forms decline. Wired for 11 languages.
- `[receiver=X]` is a NULL-definite filter (`=`, `^=`, `$=`, `*=`).
