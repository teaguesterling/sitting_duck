# Sitting Duck v1.10.2

**Release date:** 2026-08-14

`start_column` / `end_column` at `source := 'full'`.

- `read_ast` now populates `start_column` / `end_column` under
  `source := 'full'` (23 columns vs the default 21). (#100)
- Corrected the peek documentation, which described parameters that do not
  exist and omitted the one that does: `peek` is canonical
  (`none | smart | full | <int>`, optional `+schema` suffix);
  `peek_size` / `peek_mode` are superseded, and `peek_mode`'s documented
  values were never valid.
