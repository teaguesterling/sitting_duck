# Sitting Duck v1.14.0

**Release date:** 2026-09-16

Selector correctness + call-graph.

A correctness batch for `ast_select`. **Contains behaviour changes** — see
`docs/reference/css-pseudo-classes.md`.

- `:scope` / `:in-scope` split: `:scope` meant "the node IS a scope
  boundary", containment moved to `:in-scope`. (#145)
  *(This split was later found ambiguous and retired in v1.15.4 in favour of
  `::scope` / `:is-scope(X)` / `:in-scope(X)`.)*
- Bare type selectors are EXACT, not prefix; `[type^=]`, `[type$=]`,
  `[type*=]` added. (#151)
- `[file]` / `[line]` filters; `ast_selector_for`. (#154, #155)
- Malformed selectors raise instead of silently over- or under-matching. (#128)
- `:has` and adjacency fixes; `IS_CONSTITUENT` for construct sub-parts.
  (#133, #141, #139)
- `:called-by` / `:calls` are DIRECT and lambda-aware, bounded via
  `scope.function` — fixes a 59s/OOM case on large tables. (#164, #152)
