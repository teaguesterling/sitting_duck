# Sitting Duck v1.14.1

**Release date:** 2026-09-16

`::callees` made direct.

`:called-by`, `:calls` and `::callers` went direct and lambda-aware in
v1.14.0; `::callees` was still a transitive subtree scan, leaving it
inconsistent. It is now direct via `scope.function` — a call inside a lambda
inside F is F's lambda's callee, not F's.
