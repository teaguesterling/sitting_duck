## Shape A is larger than #288's example

#288 shows bare parameters and for-loop targets. Measured, one 22-line Python
file has ten such names, across five binding constructs:

```
identifier         x            <- bare parameter
identifier         zz           <- for-loop target
as_pattern_target  handle       <- with ... as
as_pattern_target  e            <- except ... as
identifier         a, b         <- tuple assignment targets
identifier         self, conn   <- bare parameters
attribute          self.cache   <- dotted tuple target
attribute          self.size    <- dotted tuple target
```

All ten have `is_name_definition(flags)` true and `is_definition(semantic_type)`
false, so all ten are absent from `ast_definitions()`. The construct list is the
same list #64 calls "likely missing", which is why #64 closes as superseded.

## Drift from the issue text

1. **#273's mechanism is narrower than reported.** The right-hand side leaks
   into `name` only when the first child after a non-identifier target is a bare
   identifier.

   | source | reported name |
   |---|---|
   | `self.db = conn` | `conn` — the RHS |
   | `obj.attr = 5` | empty |
   | `arr[0] = 6` | empty |

   So this is `FIND_IDENTIFIER` scanning past the target into the RHS, not a
   general "name comes from the RHS" rule. A fix that stops the scan at the
   target closes all three rows at once.

2. **#140a has got worse, and the issue's number no longer holds.** The issue
   records 22 of 95 `command` nodes named. Measured today it is **0 of 95**.
   `command_name` exists, 95 of them, and is also unnamed. The command word is
   present and named on `word` nodes, 161 of them. So the target is
   `command_name`'s `word` child, and the 22 in the issue text should not be
   used as a baseline. **Conflict recorded, not averaged:** either the count
   regressed after the issue was filed, or the issue counted a different set.
   Which one is not established.

3. **#140b: neither Go node is usable on its own.** `type_spec` carries the name
   `Point` but has no role flag and no definition semantic type.
   `struct_type` has a definition semantic type but an empty name. The fix must
   join them, and choosing either node alone leaves the other half missing.

4. **#277's name is an empty string, not NULL.** The issue says `<NULL>`. The
   macro filters `name IS NOT NULL AND name != ''`, so it drops either way, but
   a test asserting NULL would be wrong.

5. **#283's pointered form does not parse into a function.** Three of four
   `function_definition` rows come back for four functions.
   `pointered(Args*... args)` produces no row at all, so it is not a parameter
   defect there — the function itself is invisible. That makes it the most
   serious of the three qualified forms, and possibly a separate defect.

6. **Go `a, b := 2, 3` is one node binding two names.** Both
   `short_var_declaration` rows carry an empty name. Same shape as JS
   `let a = 1, b = 2`, where the container claims only `a`. A single-valued
   `name` column cannot express either, so the release has to state what it does
   rather than pick one name.

## #64 — close as superseded

Each construct on #64's "likely missing" list now maps onto a specific issue,
measured above:

| #64 item | Covered by | Measured |
|---|---|---|
| bare `parameter` | #288 | `x`, `self`, `conn` are shape A |
| for-loop variables | #288 | `zz` is shape A |
| `with ... as` aliases | #288 | `handle` is shape A |
| `except ... as` variable | #288 | `e` is shape A |
| destructuring targets | #288 | `a`, `b`, `self.cache`, `self.size` are shape A |
| `variable_declarator` vs declaration | #276 | `f` returned 3x |
| Go `const` / `var` declarations | #276, #277 | `const_spec` works, `short_var_declaration` unnamed |
| `field_declaration` | #276 | Java `field_declaration` + `variable_declarator` both flagged |

Nothing on the list is uncovered. #64 should become a pointer to these issues
rather than a tenth work item.

## What step 1 starts from

#273, with the narrowed mechanism from drift 1: stop `FIND_IDENTIFIER` at a
non-identifier assignment target. Expected effect, to be asserted before the
change: `self.db = conn` stops reporting `conn`, and `obj.attr = 5` and
`arr[0] = 6` are unchanged at empty.
